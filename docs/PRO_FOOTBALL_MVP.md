# Pro Football MVP

## League defaults
- 12 franchises.
- Snake draft.
- Half-PPR scoring.
- Team D/ST is a rosterable fantasy asset.
- Starting roster: QB, 2 RB, 2 WR, TE, FLEX, K, D/ST.
- Bench and IR configurable by commissioner.

## Core user loop
1. Sign up/sign in.
2. Create or join a league.
3. Create a persistent franchise identity.
4. Draft athletes and one or more D/ST units.
5. Set weekly lineup before player/team kickoff locks.
6. Follow live scoring.
7. Finalize matchup from final real-game stats.
8. Update standings, franchise history and league feed.
9. Process waivers/trades for the next event.

## Non-negotiables
- No gambling mechanics.
- No pay-to-win mechanics.
- AI presentation cannot change game state.
- Real athlete names/statistics are separated from original avatar art.
- Historical records survive across league seasons.
