# Executive-world assets

`executive-suite-v2.webp` and `front-office-destinations-v2.webp` are original generated Big Exec artwork created September 14, 2026 for the user-approved Front Office direction. No official team logos, recognizable professional player likenesses, or championship trophy silhouettes were requested or used.

The destination atlas contains four equal quadrants in order: Free Agency, Locker Room, Trade Room, League News. CSS background positioning displays each independent scene. Text, controls, franchise identity, records, and scores are rendered as HTML, never image content. Both images are compressed WebP exports, approximately 362 KB combined; no additional client JavaScript is required for imagery.
